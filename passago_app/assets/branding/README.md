# Branding files

Put the PassaGo logo files here. Use exactly these names (lowercase, underscores):

| File                      | What it is                                   |
|---------------------------|----------------------------------------------|
| `logo_wordmark.png`       | Tricycle + "PassaGo", full color (about 3x)  |
| `logo_monogram.png`       | PG monogram with speed lines                 |
| `logo_symbol.png`         | Tricycle symbol alone                        |
| `logo_wordmark.svg`       | Same as above, vector (kept for later use)   |
| `logo_monogram.svg`       |                                              |
| `logo_symbol.svg`         |                                              |
| `logo_wordmark_white.svg` | All-white wordmark, optional                 |

The app currently reads the PNG files. If a PNG is missing, it shows a plain
text placeholder instead, so nothing breaks while the files are still missing.
